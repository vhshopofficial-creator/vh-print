# VH Print — SUNMI V2s PLUS built-in printer (80 mm)

Android print service: Chrome → Print → **SUNMI 80mm (VH Print)**. Prints on the built-in printer through its
Bluetooth link (InnerPrinter 00:11:22:33:44:55, ESC/POS GS v 0 raster, 576 dots). Blank paper above/below the
content of each page is cut off. No footer, no licence, no outside libraries.

Build: push to GitHub — the action in `.github/workflows/build.yml` builds `VH-Print.apk` and publishes it as a release.

On the SUNMI: install the APK → open VH Print → Allow Bluetooth → Test print → Print settings → VH Print → On.
